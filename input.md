# SYSTEM DESCRIPTION:
Martian Survival Kit is a distributed automation platform capable of ingesting heterogeneous sensor data, normalizing it into a unified internal representation, evaluating simple automation rules, and providing a real-time dashboard for habitat monitoring.

# USER STORIES:
1. As a user, I want a dashboard that updates sensor values in real-time, so that I can monitor habitat conditions continuously.

2. As a user, I want to configure widgets to show specific sensors, so that I can customize my dashboard view according to my needs.

3. As a user, I want to see line charts of sensor data that update automatically, so that I can track trends over time.

4. As a user, I want widgets to display alerts when sensor values exceed thresholds, so that I can react immediately to critical conditions.

5. As a user, I want to view all automation rules in a dashboard, so that I can understand what conditions trigger which actuators.

6. As a user, I want to create new automation rules via the dashboard, so that I can add new behaviors without modifying the code.

7. As a user, I want to edit existing automation rules, so that I can adjust thresholds, operators, or actuator targets dynamically.

8. As a user, I want to delete outdated or unnecessary rules, so that the system only executes relevant automations.

9. As a user, I want toggle widgets for actuators, so that I can turn devices on/off directly from the dashboard.

10. As a user, I want to choose different types of visualization (e.g., line chart, live value, custom widget) for each sensor, so that I can analyze data in the most meaningful way.

11. As a user, I want to filter widgets by sensor type or location, so that I can focus on specific areas of the habitat.




17. As a user, I want to see which rules were triggered recently, so that I can verify that the automation engine is working correctly.

18. As a user, I want real-time updates of rule-triggered events via WebSocket or SSE, so that my dashboard reflects actions immediately.
